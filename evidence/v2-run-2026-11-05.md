# v2 run, 2026-11-05: tokens move with the wallet

v2 adds `request_token_transfer`: besides plain ETH transfers, the contract encodes and signs exactly
three token calls from the wallet, ERC-20 `transfer`, ERC-721 `safeTransferFrom(wallet, to, id)` and
ERC-1155 `safeTransferFrom(wallet, to, id, amount, "")`. It never builds `approve`,
`setApprovalForAll`, `permit` or any other call.
