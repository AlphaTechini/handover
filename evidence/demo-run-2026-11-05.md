Blockscout address API for wallet #2.

## What this run shows

- A pre-signed transaction kept by the seller makes the wallet `dirty`, and the web app disables
  the buy button while it is pending. Broadcasting it (anyone can) used up its nonce, the check
  turned `clean`, and only then could the buyer buy.
- After the sale the old owner's request reached the chain and the contract refused it before
  asking for any signature.
- The `dirty` state itself is not saved as a snapshot; it is visible in the demo video and follows
  from the transactions above (nonce 1 was signed at block 276342880 and mined on Sepolia only
  after the buyer broadcast it).
